## 📖 第一部分：手冊使用須知與規章 (Notice - Instrucciones)

> 對應原廠手冊第 2 頁 (Page 2)

### 1. 手冊編排說明
1. **收錄範圍**：本手冊收錄上述三款車型之全車原廠供應備用零件（包含引擎、傳動、底盤、車體鈑件、懸吊避震、轉向龍頭、電系設備與隨車工具配件）。
2. **圖號索引**：每張分解圖紙上的各個零件均標示有唯一的數字編號 (**Fig. N.**)。
3. **零件清單欄位**：
   - **Fig. N.**：分解圖編號。
   - **PART NAME / DENOMINACION**：零件名稱（原版為英文與西班牙文對照）。
   - **Valid for / Válido para**：適用車型標記（例如標註 `V9A1` 表示僅 Vespa 90 適用；標註 `V5A1` 則為 50cc 專用；箭頭雙向貫穿表示三款車型共用）。
   - **Spare parts / Piezas de repuesto**：Piaggio 原廠設計圖號 / 零件料號。
   - **No. off / Cantidad**：每輛車裝配之使用數量。
4. **料號編碼規則**：
   - 前綴帶有 **「S.」** 開頭（例如 `S. 1107` 螺帽、`S. 3057` 平華司、`S. 7160` 軸承、`S. 8720` 油封）為 Piaggio 原廠規範之**標準規格件 (Standard Parts)**。
   - 純數字編號（例如 `78330` Vespa 90 曲軸、`98375` 汽缸組）為各車型專用之**特製沖壓或精密機械加工件**。

### 2. 全書 16 大分解圖表 (Tavole) 系統分區

## 📌 第三部分：特殊配件組裝施工說明 (Notice - Advertencia)

> 對應原廠手冊第 34 頁 (Page 34)

### 掛包勾 (Hooks for bag / Ganchos porta-bolsa) 安裝說明
* **配件料號**：`110612`
* **適用對象**：安裝於原廠單人彈簧皮革坐墊 (Normal single saddle)
* **原廠施工步驟指引**：
  1. 拆卸單人坐墊下方的中央大彈簧 (Dismount the seat central spring)。
  2. 在坐墊金屬支架前端正中央，使用鑽頭鑽出一個 **直徑 7.5 mm (Ø 7.5)** 的通孔。
  3. 將掛包勾件由上方穿入，下側依序裝入平華司、彈簧防鬆墊圈與專用螺帽緊固。
  4. 重新裝回中央支撐大彈簧，即完成原廠規格之斜板置物勾安裝。
