1. 手冊編排說明

• 收錄範圍：本手冊收錄上述三款車型之全車原廠供應備用零件（包含引擎、傳動、底盤、車體鈑件、懸吊避震、轉向龍頭、電系設備與隨車工具配件）。
• 圖號索引：每張分解圖紙上的各個零件均標示有唯一的數字編號 (Fig. N.)。
• 零件清單欄位：
  • Fig. N.：分解圖編號。
  • PART NAME / DENOMINACION：零件名稱（原版為英文與西班牙文對照）。
  • Valid for / Válido para：適用車型標記（例如標註 V9A1 表示僅 Vespa 90 適用；標註 V5A1 則為 50cc 專用；箭頭雙向貫穿表示三款車型共用）。
  • Spare parts / Piezas de repuesto：Piaggio 原廠設計圖號 / 零件料號。
  • No. off / Cantidad：每輛車裝配之使用數量。
• 料號編碼規則：
  • 前綴帶有 「S.」 開頭（例如 S. 1107 螺帽、S. 3057 平華司、S. 7160 軸承、S. 8720 油封）為 Piaggio 原廠規範之標準規格件 (Standard Parts)。
  • 純數字編號（例如 78330 Vespa 90 曲軸、98375 汽缸組）為各車型專用之特製沖壓或精密機械加工件。

2. 全書 16 大分解圖表 (Tavole) 系統分區

  • 引擎與動力系統 (Engine / Motor)：T. I 至 T. VI
  • 車體與懸吊系統 (Chassis / Bastidor)：T. VII 至 T. IX
  • 前叉轉向柱與懸吊 (Steering column / Dirección)：T. X 至 T. XI
  • 龍頭把手與儀表 (Handlebars / Manillar)：T. XII
  • 全車鋼索與煞車踏板 (Transmissions / Transmisiones)：T. XIII
  • 全車電系設備與配線 (Electrical equipment / Equipo eléctrico)：T. XIV 至 T. XV
  • 車輪、隨身工具與選配套件 (Wheel, Tools, Accessories)：T. XVI

對應原廠手冊第 34 頁 (Page 34)

掛包勾 (Hooks for bag / Ganchos porta-bolsa) 安裝說明

  • 配件料號：110612
  • 適用對象：安裝於原廠單人彈簧皮革坐墊 (Normal single saddle)
  • 原廠施工步驟指引：
• 拆卸單人坐墊下方的中央大彈簧 (Dismount the seat central spring)。
• 在坐墊金屬支架前端正中央，使用鑽頭鑽出一個 直徑 7.5 mm (Ø 7.5) 的通孔。
• 將掛包勾件由上方穿入，下側依序裝入平華司、彈簧防鬆墊圈與專用螺帽緊固。
• 重新裝回中央支撐大彈簧，即完成原廠規格之斜板置物勾安裝。
